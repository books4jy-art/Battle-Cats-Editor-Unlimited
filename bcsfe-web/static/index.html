Battle Cats Unlimited

⚠ Warning: no limits This editor lets you go far past the game's own limits: items, Cat Food and tickets far past the danger point, up to what the save file can hold. (Levels above a character's maximum are saved, but the game lowers them back to the maximum when it loads the account.) The game was never made for these values. They can crash the game, be reset by the game server, or get your account banned. Use a spare account, keep your original transfer codes, and use at your own risk.

Enter a transfer code to edit your save and get new codes back, or drop in a SAVE_DATA file to edit it directly.

In the game: Change Device → Data Transfer. Codes work once, so you'll get new ones after editing.

Save your current account first. Make sure to save your current account's codes (Change Device → Start Data Transfer in the game) before transferring a new account onto your device.

        Type a level like 50+10 (level + plus level). Leave a side out to keep it, e.g. +10 only changes the plus level.         How it works

        1. In Battle Cats, open Change Device → Data Transfer and note the transfer code and confirmation code.
        2. Enter them here, pick your country, and choose what to change on the right.
        3. The editor downloads your save, applies the edits and uploads it again. You get new codes — the old ones stop working once used.
        4. Back in the game, choose Resume Data Transfer and enter the new codes.
        5. Download the original backup the site gives you, in case you want to undo.

        Rooted or emulator user? Use the Save file tab with your SAVE_DATA instead — nothing is uploaded to the game servers in that mode.
